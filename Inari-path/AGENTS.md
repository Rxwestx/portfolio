# Overview
 このアプリケーションは PHP, Laravel v11, PostgreSQL, Laravel Sail, HTML, CSS, JS で構成されるダッシュボードです。 
vite, tailwindcss,も使われています。
 
# デザインガイド
 
## 概要

-  全体的にフラットデザインで、親しみやすさを感じるデザインにする
-  信頼感とスマートさのあるデザイン
- モダンなデザイン
- やさしい
- 成長感
- 学習継続
- ダッシュボードは見やすく、情報が整理されている
- ゲーム感はあるが、学習アプリとしての見やすさも残す
- 既存の画面構成を大きく壊さず、配色・余白・タイポグラフィでモダン化する
- カードUI中心
- Instagramのような軽さ・見やすさ
 
## 配色
 
-   背景色: #f3f7f9
-   ベースカラー（基本となる色。見出しやヘッダーなど、面積の大きい要素に使う色）: #9ecda5
-   アクセントカラー（ボタンやタブなどに使う色）: #41956a
 
## コーディングルール
 
-   CSS はなるべく　TailwindCSS のクラスのみで実装すること
-   どうしても独自にクラスと CSS を追記する場合は別途 custom.css に記述すること
- 既存クラスを活かして、配色とUIだけモダン化すること
 
## Font
 
-   プレーンテキストに使うフォント: M PLUS 1
-   見出しに使うフォント: Montserrat
 
## Padding & Margin & Font Size
 
-   8 の倍数にしたがう。グルーピングするなら 8~24px, ジャンプ率を設けるなら 32~72px
-   基本のフォントサイズは PC, SP ともに 16px。見出しは 20, 24, 28, 32px、注釈など補足情報は 12px にするなど 4 の倍数で変化させる。
 
## その他
 
-   ボタンなど押せる要素は角丸 5px を適応させる
-   押せない要素は角丸 0px で統一
